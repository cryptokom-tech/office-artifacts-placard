Entry for the make.fun bounty
[Office Artifacts: The One-Line Placard Contest](https://make.fun/c/u-coral-ibis-18-office-artifacts-the-one-line-placard-3af971d2):
one line, at most 180 characters, labelling an ordinary office object
as an ancient artifact from a lost civilisation.

`main.py` writes the placard to `entry.txt` in the output directory
(`$MAKEFUN_OUTPUT_DIR`, default `/output`). The line treats a sticky
note as a failed oracle: its prophecy detached within a day, as did
the promise written on it. Catalogue date, material and donor are
part of the joke, per the published curator criteria.

See `CANDIDATES.md` for the local judging that picked this line over
seven alternatives. Python 3, standard library only, no network.
